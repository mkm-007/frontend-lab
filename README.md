# frontend-lab

React + TypeScript UI lab — reusable components and energy fleet monitoring views.

| View | File | JD fit |
|------|------|--------|
| Fleet dashboard | `src/App.tsx` | Commercial UI, IoT fleet monitoring |
| Telemetry cards | `TelemetryCard.tsx` | Live site inspection |
| Status table | `SiteStatusTable.tsx` | Scalable fleet aggregation |

```bash
cd labs/frontend-lab
npm install
npm test
npm run dev
```
